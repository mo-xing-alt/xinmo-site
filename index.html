往仓库里加新东西

已经登录的朋友可以自助上传：点顶部「上传」，选好文件填好信息，提交后直接进仓库、自动出现在上面的资源列表里，不用懂代码。站主自己也可以在 resources.js 里登记更精细的资源。

上传资料

  1. 1把新页面放到 resources/ 或 tools/ 下的新文件夹，入口文件命名为 index.html。
  2. 2打开 assets/js/resources.js，在 items 数组里复制一段并改成新资源的信息。
  3. 3把更新后的整个站点文件夹重新上传 / 发布即可。想让子页面也能跳回首页，照抄现有页面底部的 repo-back 链接就行。
assets/js/resources.js
// 在 items 数组里新增一条
{
  id: "my-new-tool",
  title: "我的新工具",
  subtitle: "一句话副标题",
  description: "简单说明它能做什么。",
  category: "tool",   // study / tool / doc
  icon: "tool",
  accent: "indigo",
  url: "./tools/my-new-tool/index.html",
  tags: ["在线用", "免登录"],
  meta: "单页应用",
  status: "可用",
  updated: "2026-11-10"
}
