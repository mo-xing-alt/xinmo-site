一函数与极限

这一章是地基。极限算不出来，后面的连续、导数都写不下去。

必背公式与结论（够用就行）

两个重要极限：lim(x→0) sin x / x = 1；lim(x→∞)(1 + 1/x)x = e，lim(x→0)(1 + x)1/x = e。

等价无穷小（x→0）：sin x ~ tan x ~ arcsin x ~ arctan x ~ ln(1+x) ~ ex − 1 ~ x；1 − cos x ~ x2/2；(1+x)a − 1 ~ ax。

有理式求极限（x→∞）：分子分母同除以最高次幂，看谁次数高。分子次数高趋于 ∞，分母次数高趋于 0，次数相同就是最高次项系数之比。

0/0 型三招：因式分解约去零因子、等价无穷小替换（只对乘积因子）、根式有理化。

无穷小 × 有界量 = 无穷小（例如 x·sin(1/x)，x→0）。

1选择lim(x→2) (x2 − 4)/(x − 2) 等于（　）
A. 0B. 2C. 4D. 不存在
答案C

解析 · 一步一步来

1

先把 x = 2 代进去，看看能不能直接算出数

分子：22 − 4 = 4 − 4 = 0；分母：2 − 2 = 0。得到 0/0。

2

判断类型：0/0 不能直接写答案

0/0 是一个“没有意义”的式子，不是数字 0。它说明分子分母同时含有让它们变成 0 的因子，需要先约分。

3

把分子分解，目的是找出能和分母约掉的因子

x2 − 4 = x2 − 22 = (x + 2)(x − 2)。

4

约去公因子 (x − 2)，说明为什么可以约

原式 = (x + 2)(x − 2)/(x − 2) = x + 2。之所以能约，是因为 x→2 只表示“x 无限接近 2”，并不等于 2，所以 x − 2 ≠ 0，可以做除法。

5

现在分母不再是 0，直接代入求值

lim(x→2)(x + 2) = 2 + 2 = 4。

用到：平方差公式 a2 − b2 = (a + b)(a − b)；极限四则运算法则 lim f(x)/g(x) = lim f(x) / lim g(x)（要求分母极限不为 0）。

错项排查

  • A看到分子分母都算成 0，就把 0/0 当成了 0。0/0 不是数，必须继续变形。
  • B只把 x = 2 代进了 x 这一项，漏掉了 +2。正确结果是 2 + 2 = 4。
  • C约分后代入得 4，正确。
  • D认为“分母为 0 所以极限不存在”。只有当分子不趋于 0 时才是这样；这里分子也趋于 0，约分后极限存在。
2选择lim(x→∞) (3x2 + 2x − 1)/(x2 − 5) 等于（　）
A. 0B. 1C. 3D. ∞
答案C

解析 · 一步一步来

1

先看 x 趋于无穷时，分子分母各自往哪走

x→∞ 时，3x2 和 x2 都无限变大，所以是 ∞/∞ 型。∞/∞ 也没有直接意义，不能写答案。

2

决定同除以最高次幂 x2，理由是让每一项都变成能算的数

分子分母同时除以 x2（同时除同一个不为 0 的量，分数值不变）：
分子 = 3 + 2/x − 1/x2，分母 = 1 − 5/x2。

3

用“常数除以无穷大趋于 0”把带 x 的项全部消掉

x→∞ 时，2/x → 0，1/x2 → 0，5/x2 → 0。于是分子 → 3 + 0 − 0 = 3，分母 → 1 − 0 = 1。

4

分子分母的极限都存在，用四则运算相除

原式 = 3/1 = 3。

用到：lim(x→∞) 1/xk = 0（k 为正整数）；极限四则运算法则。口诀：分子分母次数相同，极限就是最高次项系数之比，本题 3 : 1。

错项排查

  • A0 是“分母次数比分子高”时的结果，本题两边都是 2 次，不能得 0。
  • B1 来自只比较了分母的系数 1，没有把分子的 3 算进去。
  • C同除 x2 后得 3/1 = 3，正确。
  • D∞ 是“分子次数比分母高”时的结果；本题次数相同，不会发散。
3填空lim(x→0) sin 3x / x = ______
答案3

解析 · 一步一步来

1

先代入 x = 0 看类型

分子 sin 0 = 0，分母 0，是 0/0 型，需要变形。

2

确定变形目标：凑成第一重要极限 sin u / u 的样子

重要极限要求 sin 后面跟的东西，和分母完全一样。现在 sin 后面是 3x，分母却是 x，不一致。

3

用换元让式子整齐：令 u = 3x

当 x→0 时，u = 3x → 0；并且 x = u/3。代进去：sin 3x / x = sin u / (u/3) = 3 · sin u / u。

4

套重要极限，把常数 3 留在外面

lim(u→0) 3 · sin u/u = 3 × 1 = 3。

用到：第一重要极限 lim(u→0) sin u / u = 1；也可用等价无穷小 sin 3x ~ 3x，直接得 3x/x = 3。

填空题常见错答：写 1，是把 sin 3x 当成了 ~ x，忘了系数 3；写 0，是把分子当成 0 直接约掉。

4填空lim(x→∞) (1 + 2/x)x = ______
答案e2

解析 · 一步一步来

1

先看底数和指数分别往哪走

x→∞ 时 2/x → 0，所以底数 1 + 2/x → 1；指数 x → ∞。这是“1 的无穷次方”型，属于第二重要极限的题型。

2

写出要凑的目标形式

公式是 lim(u→0)(1 + u)1/u = e。它的特点是：括号里加的是 u，指数恰好是 u 的倒数 1/u。

3

换元，把 2/x 整体看成 u

令 u = 2/x，则 x = 2/u。当 x→∞ 时 u→0。原式变成 (1 + u)2/u。

4

用幂的运算法则把指数拆成“1/u 的倍数”

(1 + u)2/u = [(1 + u)1/u]2，依据是 (am)n = amn。

5

括号内套第二重要极限，再平方

中括号 → e，所以原式 = e2。

用到：第二重要极限 lim(u→0)(1 + u)1/u = e；幂的运算法则。

填空题常见错答：写 e，是漏掉了平方；写 e1/2，是把指数配反了（应乘 2，不是除 2）。

5计算求 lim(x→0) (1 − cos x)/x2
答案1/2

解析 · 一步一步来

1

代入看类型

1 − cos 0 = 1 − 1 = 0，分母 02 = 0，是 0/0 型。

2

想不起来等价公式时，可以用半角公式自己推

由 1 − cos x = 2sin2(x/2)，原式 = 2sin2(x/2) / x2 = 2 · [sin(x/2)/(x/2)]2 · (1/4)（因为 sin2(x/2) = [sin(x/2)]2，而分母 x2 = 4·(x/2)2）。

3

这一步直接查等价无穷小更快，说明为什么能换

x→0 时 1 − cos x ~ x2/2。因为 1 − cos x 在这里是整个分子，是一个“乘积因子”，符合等价替换的条件。

4

替换后约掉 x2

原式 = lim (x2/2)/x2 = 1/2。

用到：等价无穷小 1 − cos x ~ x2/2（来自 cos x = 1 − x2/2 + o(x2)）；等价无穷小替换定理：乘除因子可以直接换，加减项不能。

常见错答：写 0（把 1 − cos x 当成 0）；写 1（误以为 1 − cos x ~ x2，丢了 1/2）。

6计算求 lim(x→0) (√(1+x) − 1)/x
答案1/2

解析 · 一步一步来

1

代入看类型

√(1+0) − 1 = 0，分母 0，是 0/0 型。

2

分子是“根号减一个数”，直接算没法约分，所以先有理化

把分子分母同乘分子的共轭式 √(1+x) + 1。依据是 (√a − 1)(√a + 1) = a − 1，乘完根号就消失了。

3

写出乘完的结果，分子用平方差

分子 = (1 + x) − 1 = x；分母 = x(√(1+x) + 1)。

4

约去公因子 x（x→0 但 x ≠ 0）

原式 = 1/(√(1+x) + 1)。

5

分母不再是 0，代入求值

= 1/(1 + 1) = 1/2。

用到：平方差公式；有理化技巧。也可用等价无穷小 (1+x)a − 1 ~ ax，取 a = 1/2 得 x/2，结果相同。

常见错答：写 1（把 √(1+x) 直接当成 1 + x）；写 0（只看到分子趋于 0）。

7计算求 lim(x→3) (x2 − 9)/(x2 − 5x + 6)
答案6

解析 · 一步一步来

1

先代入 x = 3

分子 9 − 9 = 0；分母 9 − 15 + 6 = 0。0/0 型。

2

分子用平方差分解

x2 − 9 = (x − 3)(x + 3)。

3

分母用十字相乘分解，找一个能约掉的因子

要找两个数，乘积 6、和 −5，就是 −3 和 −2，所以 x2 − 5x + 6 = (x − 3)(x − 2)。

4

约去公共的零因子 (x − 3)

原式 = (x + 3)/(x − 2)。

5

代入 x = 3 求值

= (3 + 3)/(3 − 2) = 6/1 = 6。

用到：因式分解（平方差、十字相乘）；0/0 型约去零因子法。

常见错答：写“不存在”，只因为分母为 0；写 0，把分子分母的 0 直接约掉。分母为 0 时要先看分子是否含同一个因子。

8计算求 lim(x→0) x·sin(1/x)
答案0

解析 · 一步一步来

1

先分别看两个因子在 x→0 时的情况

x → 0，所以第一个因子是无穷小；sin(1/x) 里 1/x → ∞，正弦值在 −1 和 1 之间来回摆动，它本身没有极限。

2

不要因为“第二个因子没极限”就判整题不存在，先看它有没有界

不管 1/x 多大，正弦值永远满足 |sin(1/x)| ≤ 1，所以它是有界量。

3

套“无穷小 × 有界量”的结论

无穷小乘有界量仍是无穷小，所以整个乘积趋于 0。

4

用不等式再确认一遍（考试写这句更稳）

|x·sin(1/x) − 0| = |x|·|sin(1/x)| ≤ |x| → 0，由夹逼准则，极限为 0。

用到：无穷小与有界函数的乘积仍是无穷小；夹逼准则（两边夹住，两边都趋于同一个数，中间也趋于它）。

常见错答：写“不存在”，是被 sin(1/x) 的振荡带偏；写 1，是误以为 sin(1/x) → 1。

9计算求 lim(x→∞) (2x + 1)/(x2 + 3)
答案0

解析 · 一步一步来

1

判断类型：分子分母都趋于无穷

x→∞ 时分子 2x + 1 → ∞，分母 x2 + 3 → ∞，是 ∞/∞ 型。

2

找出最高次幂，同除它

最高次是 x2（在分母）。分子分母同除 x2：分子 = 2/x + 1/x2，分母 = 1 + 3/x2。

3

让带 x 的项全部归零

x→∞ 时 2/x → 0，1/x2 → 0，3/x2 → 0，于是分子 → 0，分母 → 1。

4

相除得结果

原式 = 0/1 = 0。

用到：lim(x→∞) 1/xk = 0。结论可以直接记：分母次数高 → 极限 0；分子次数高 → 极限 ∞；次数相同 → 系数比。

常见错答：写 ∞（以为“无穷比无穷还是无穷”）；写 2（把 2x 的系数 2 和 x2 的系数 1 直接相比，但两者次数不同，不能这么比）。

10填空lim(x→1) (x3 − 1)/(x − 1) = ______
答案3

解析 · 一步一步来

1

代入 x = 1

分子 1 − 1 = 0，分母 0，是 0/0 型。

2

用立方差公式分解分子，目的是造出 (x − 1)

a3 − b3 = (a − b)(a2 + ab + b2)，取 a = x、b = 1，得 x3 − 1 = (x − 1)(x2 + x + 1)。

3

约去 (x − 1)

原式 = x2 + x + 1（因为 x→1 时 x ≠ 1，可以约）。

4

代入求值

= 1 + 1 + 1 = 3。

用到：立方差公式。推广一下：xn − 1 = (x − 1)(xn−1 + xn−2 + … + 1)，除完那一串在 x = 1 处正好等于 n。

填空题常见错答：写 0（把 x3 − 1 当成 (x − 1)3）；写 1（把 x2 + x + 1 在 x = 1 处算成 1）；写 ∞（只看到分母为 0）。

11选择当 x→0 时，与 x 等价的无穷小是（　）
A. 1 − cos xB. sin xC. x2D. ln(1 + x2)
答案B

解析 · 一步一步来

1

先明确“等价”的判定标准

若 lim(α/β) = 1，就说 α 与 β 等价，记作 α ~ β。所以判断方法就是：把选项除以 x，看极限是不是 1。

2

逐项算比值

A：(1 − cos x)/x = [(1 − cos x)/x2]·x → (1/2)·0 = 0；
B：sin x/x → 1；
C：x2/x = x → 0；
D：ln(1 + x2)/x ~ x2/x = x → 0。

3

只有比值为 1 的才是等价

B 的比值极限是 1，符合定义；A、C、D 的比值都趋于 0，说明它们比 x 更快趋于 0，是“高阶无穷小”。

用到：等价无穷小定义 lim α/β = 1；常用等价式 sin x ~ x、1 − cos x ~ x2/2、ln(1 + u) ~ u。

错项排查

  • A1 − cos x ~ x2/2，是二阶无穷小，与 x 不等价（比值 → 0）。它常被误记成 ~ x。
  • Bsin x ~ x，这是最基础的一条等价式，正确。
  • Cx2 与 x 同趋于 0，但阶数不同，比值 x → 0，不等价。
  • Dln(1 + x2) ~ x2，同样是二阶，不等价。
12填空函数 f(x) = √(4 − x2) + 1/(x − 1) 的定义域是 ______
答案[−2, 1) ∪ (1, 2]

解析 · 一步一步来

1

先找出所有“有限制”的地方

这个函数有两处限制：一是根号，二是分母。两个条件必须同时满足，最后取交集。

2

处理根号：偶次根号内必须非负

4 − x2 ≥ 0，移项得 x2 ≤ 4，两边开方得 |x| ≤ 2，即 −2 ≤ x ≤ 2。

3

处理分母：分母不能为 0

x − 1 ≠ 0，即 x ≠ 1。

4

把两个条件取交集

在 [−2, 2] 里挖掉 x = 1，得到 [−2, 1) ∪ (1, 2]。

用到：偶次根号要求被开方式 ≥ 0；分式要求分母 ≠ 0；不等式 x2 ≤ a（a > 0）的解是 −√a ≤ x ≤ √a。

填空题常见错答：写 [−2, 2]，漏了 x ≠ 1；写 (−2, 2)，把根号允许取 0 的两个端点也挖掉了；写 [−2, 1] ∪ [1, 2]，1 处仍然有定义。端点开闭是这道题唯一的坑。

二函数的连续性与间断点

这一章考法很固定：判断间断点类型、求分段函数里的未知参数。

必背公式与结论

连续的三个条件：在 x0 有定义；lim(x→x0) f(x) 存在；极限值等于函数值。三句话合成一句就是 lim(x→x0) f(x) = f(x0)。

左右连续：左极限 = 右极限 = 函数值，三者相等才连续。

间断点分类：左右极限都存在的叫第一类（相等是可去间断点，不等是跳跃间断点）；左右极限至少有一个不存在的叫第二类（趋于无穷是无穷间断点，来回摆动是振荡间断点）。

闭区间上连续函数的性质：有界性、最大值最小值定理、介值定理、零点定理（两端异号，中间必有零点）。

初等函数在其定义区间内连续，所以找间断点只看“分母为 0、对数真数为 0、分段点”这几处。

1选择函数 f(x) = (x2 − 1)/(x − 1) 在 x = 1 处是（　）
A. 可去间断点B. 跳跃间断点C. 无穷间断点D. 连续点
答案A

解析 · 一步一步来

1

先看这个点有没有定义

x = 1 时分母 1 − 1 = 0，函数没有意义，所以 x = 1 是间断点，一定不是连续点。

2

再算 x→1 时的极限，判断属于哪一类

分子 x2 − 1 = (x − 1)(x + 1)，约去 (x − 1) 得 x + 1，所以 lim(x→1) f(x) = 2。左右两侧都是 2，极限存在且有限。

3

对照分类标准下结论

极限存在、但函数在该点无定义，属于“可去间断点”——只要补充定义 f(1) = 2，函数就连续了。

用到：连续定义；间断点分类。判断顺序永远是：先算左右极限，再看函数值。

错项排查

  • A极限存在但无定义，可去，正确。
  • B跳跃要求左右极限都存在但不相等（例如分段函数在分界点两边接到不同高度），这里两侧都趋于 2。
  • C无穷间断点要求极限为 ∞，这里极限是有限的 2。
  • D连续要求有定义且函数值等于极限，x = 1 处根本没定义。
2选择函数 f(x) = 1/x 在 x = 0 处是（　）
A. 可去间断点B. 跳跃间断点C. 无穷间断点D. 振荡间断点
答案C

解析 · 一步一步来

1

先确认它是间断点

x = 0 时分母为 0，函数无定义，是间断点。

2

分别算左右极限，注意符号方向

x→0+ 时 x 是正的小数，1/x → +∞；x→0− 时 x 是负的小数，1/x → −∞。

3

按“极限是否存在”先分大类

左右极限都不是有限数，属于第二类间断点；再按“是不是趋于无穷”细分，是无穷间断点。

用到：第二类间断点定义（左右极限至少一个不存在）；无穷间断点的判定（极限为 ∞）。

错项排查

  • A可去间断点要求极限是一个有限数，这里不存在有限极限。
  • B跳跃间断点要求左右极限都是有限数、只是不相等，而这里两边都发散。
  • C单侧趋于无穷，无穷间断点，正确。
  • D振荡间断点的典型是 sin(1/x)：值在 −1 和 1 之间来回跳，不朝无穷跑；1/x 是一路冲向无穷。

三导数与微分

分值最重，但套路最少：背熟导数表，练熟链式法则，计算题基本稳了。

必背公式与结论

导数定义：f′(x0) = lim(Δx→0) [f(x0+Δx) − f(x0)]/Δx = lim(x→x0) [f(x) − f(x0)]/(x − x0)。

基本导数表：(xa)′ = axa−1，(sin x)′ = cos x，(cos x)′ = −sin x，(tan x)′ = sec2x，(ex)′ = ex，(ax)′ = axln a，(ln x)′ = 1/x，(arctan x)′ = 1/(1+x2)，(arcsin x)′ = 1/√(1−x2)。

乘除法则：(uv)′ = u′v + uv′；(u/v)′ = (u′v − uv′)/v2。

链式法则：y = f(u)，u = g(x)，则 dy/dx = f′(u)·g′(x)。由外往里剥，一层一层乘。

隐函数：两边对 x 求导，把 y 看成 x 的函数，遇到 y 就多乘一个 y′，再解出 y′。

参数方程：x = φ(t)，y = ψ(t)，则 dy/dx = ψ′(t)/φ′(t)。

微分：dy = f′(x)dx；切线方程 y − f(x0) = f′(x0)(x − x0)。

12填空设 y = x2，则 dy|x=1 = ______
答案2dx

解析 · 一步一步来

1

先求导函数

y′ = (x2)′ = 2x。

2

套微分公式，写出一般的 dy

dy = y′dx = 2x dx。注意 dx 是“自变量的微小增量”，必须带着。

3

把 x = 1 代入，得到该点处的微分

dy|x=1 = 2×1·dx = 2dx。

用到：微分定义 dy = f′(x)dx；(x2)′ = 2x。

填空题常见错答：写 2（漏了 dx，微分是一个带 dx 的量，不是一个数）；写 2x（没有代入 x = 1）；写 1（把 x = 1 代进了原函数 y = 1）。

四微分中值定理与导数应用

单调性、极值、最值，是整张卷子里最好拿分的大题，流程固定。

必背公式与结论

罗尔定理：[a,b] 连续、(a,b) 可导、f(a) = f(b)，则存在 ξ ∈ (a,b)，使 f′(ξ) = 0。

拉格朗日中值定理：前两个条件同上，则存在 ξ ∈ (a,b)，使 f(b) − f(a) = f′(ξ)(b − a)。

单调性：区间内 f′(x) > 0 则单调递增，f′(x) < 0 则单调递减。个别点导数为 0 不影响整个区间的单调性。

极值必要条件：若 f 在 x0 可导且取极值，则 f′(x0) = 0（x0 是驻点）。

第一充分条件：f′ 在 x0 两侧变号。左正右负 → 极大值；左负右正 → 极小值；不变号 → 不是极值。

第二充分条件：f′(x0) = 0 且 f″(x0) ≠ 0：f″ < 0 取极大值，f″ > 0 取极小值。

求最值：把所有驻点、导数不存在的点、区间端点都算出来，比大小。

1计算验证 f(x) = x2 在 [0,2] 上满足拉格朗日中值定理，并求出定理中的 ξ。
答案ξ = 1

解析 · 一步一步来

1

先验证定理的两个条件，这是“验证”类题目的必答内容

f(x) = x2 是多项式，多项式在整条数轴上连续、可导，所以它在闭区间 [0,2] 上连续，在开区间 (0,2) 内可导。

2

写出定理的等式

f(b) − f(a) = f′(ξ)(b − a)，其中 a = 0，b = 2。

3

把已知量一个个代进去

f(2) = 22 = 4，f(0) = 0，b − a = 2 − 0 = 2，所以左边 4 − 0 = 4，右边 = f′(ξ)·2。

4

先求导函数，再解方程

f′(x) = 2x，所以 f′(ξ) = 2ξ。方程 4 = 2ξ·2 = 4ξ，解得 ξ = 1。

5

检查 ξ 是否落在开区间内，这一步是验证而不是多余

1 ∈ (0,2)，符合要求。

用到：拉格朗日中值定理 f(b) − f(a) = f′(ξ)(b − a)；多项式处处连续可导。

常见错答：只写 ξ = 1，不验证条件；解出 ξ 后不检查是否在 (0,2) 内；把 b − a 写成 a − b。

1

单调性看导数的正负，所以先求导

f′(x) = 2x − 4（逐项求导，常数 3 的导数为 0）。

解析 · 一步一步来

1

定义域先写清楚，再求导

多项式定义域是全体实数。f′(x) = 3x2 − 3。

2

提公因式并因式分解，方便找零点

3x2 − 3 = 3(x2 − 1) = 3(x − 1)(x + 1)。令 f′ = 0，得 x = 1 或 x = −1，这两个是驻点。

3

驻点把数轴分成三段，各取一个测试点判断导数符号

取 x = −2：f′ = 3(4) − 3 = 9 > 0；
取 x = 0：f′ = 0 − 3 = −3 < 0；
取 x = 2：f′ = 12 − 3 = 9 > 0。

4

按导数符号写单调区间

(−∞,−1) 上 f′ > 0，递增；(−1,1) 上 f′ < 0，递减；(1,+∞) 上 f′ > 0，递增。

5

用第一充分条件判断极值：看导数在驻点两侧是否变号

x = −1：左正右负 → 极大值，f(−1) = (−1)3 − 3(−1) = −1 + 3 = 2。
x = 1：左负右正 → 极小值，f(1) = 1 − 3 = −2。

用到：第一充分条件；因式分解；(x3)′ = 3x2。答题格式：求导 → 求驻点 → 列表判号 → 写结论。

常见错答：单调区间写成 (−∞,−1) ∪ (1,+∞)（不能用并集，要用“和”或逗号）；只写“x = −1 是极大值点”而不写极大值 2；把极大极小判反。

1

先明确最值只可能在三类点上出现

驻点、导数不存在的点、区间端点。三类都要算，缺一不可。

找闭区间内的驻点（上一题已经求过）

第一件事是写定义域，因为有对数

求导，并通分方便看符号

7选择设 f 在 x0 处可导，则 f 在 x0 处取得极值的必要条件是（　）
A. f′(x0) = 0B. f″(x0) = 0C. f′(x0) > 0D. f 在 x0 连续
答案A

解析 · 一步一步来

1

先明确“必要条件”的含义

“P 是 Q 的必要条件”意思是：Q 成立时 P 一定成立（Q ⇒ P）。所以这里要找一个“只要取极值就必然成立”的结论。

2

调出费马引理

若 f 在 x0 可导且取极值，则 f′(x0) = 0。题目正好给了“可导”这个前提，条件完全对得上。

3

说明它只是必要、不是充分

反过来不成立：x3 在 0 处 f′(0) = 0，却不取极值。所以“f′ = 0”不能拿来判定极值，只能作为必要条件。

用到：费马引理；充分与必要条件的区别。

错项排查

  • A费马引理给出的正是这一条，正确。
  • B二阶导数为 0 与极值没有必然联系。反例：x4 在 0 处 f″(0) = 0，却取极小值；x3 在 0 处 f″(0) = 0，却不取极值。
  • Cf′ > 0 说明函数正在上升，恰恰排除了极值（极值点两侧必须一升一降或反过来）。
  • D这一条其实不成立：极值不要求连续。例如 f(0) = 1、其余点 f(x) = 0，则 0 处取极大值 1，但函数在 0 处不连续。
8计算求 y = x + 1/x（x > 0）的最小值。

解析 · 一步一步来

1

先看清定义域，题目已经限定 x > 0

所以只在这个范围内讨论，不用管 x < 0 的部分。

2

求导，通分

y′ = 1 − 1/x2 = (x2 − 1)/x2。

11判断若 f′(x0) = 0，则 x0 一定是 f 的极值点。（　）
答案错误

1

判断一个全称命题为假，只需举一个反例

要找“f′(x0) = 0 但不是极值点”的函数。

2

取最简单的立方函数试一下

必背公式与结论

极值点是横坐标 x，极值是对应的函数值 y。答题要写“在 x = … 处取极大值 …”。

解析 · 一步一步来

1

(2x3)′ = 6x2，(3x2)′ = 6x，所以 f′(x) = 6x2 − 6x。

2

提公因式并解方程找驻点

6x2 − 6x = 6x(x − 1) = 0，得 x = 0 或 x = 1。

3

分三段取测试点，判断导数符号

取 x = −1：6(−1)(−2) = 12 > 0，递增；
取 x = 0.5：6(0.5)(−0.5) = −1.5 < 0，递减；
取 x = 2：6(2)(1) = 12 > 0，递增。

4

看谁满足“左正右负”

x = 0 左边增、右边减，是极大值点；x = 1 左边减、右边增，是极小值点。题目问极大，只答 0。

5

把极大值点代回原函数求极大值

f(0) = 2×0 − 3×0 = 0，所以极大值是 0。

用到：第一充分条件；(xn)′ = nxn−1。注意“极大值点”填 x，“极大值”填 y。

填空题常见错答：第一空填 1（把极小值点当极大）；第二空填 −1（那是极小值 f(1) = 2 − 3 = −1）；两空都填 0 却把顺序弄反。

2填空f(x) = x2 − 2x + 3 的极小值是 ______
答案2

解析 · 一步一步来

1

求一阶导，找驻点

f′(x) = 2x − 2，令 2x − 2 = 0 得 x = 1。

2

用第二充分条件判断是极大还是极小

f″(x) = 2 > 0，恒为正，所以 x = 1 处取极小值。

3

把 x = 1 代回原函数算极小值

f(1) = 1 − 2 + 3 = 2。

4

换一种方法验算（配方法）

x2 − 2x + 3 = (x − 1)2 + 2。平方项最小为 0，所以最小值是 2，在 x = 1 时取到，与上面一致。

用到：第二充分条件；配方法 x2 + bx + c = (x + b/2)2 + c − b2/4。

填空题常见错答：填 1（那是极小值点，不是极小值）；填 −1（配方符号错）；填 3（直接把常数项当答案）。

3判断f(x) = |x| 在 x = 0 处取得极小值，但 f 在 x = 0 处不可导。（　）
答案正确

解析 · 一步一步来

1

先用定义验证“极小值”：比较 0 附近所有点的函数值

f(0) = |0| = 0。对任何 x ≠ 0，都有 |x| > 0 = f(0)，也就是 0 附近的所有点函数值都不小于它，符合极小值的定义。

2

再用左右导数验证“不可导”

左导数：x→0− 时 |x| = −x，比值为 (−x)/x = −1；右导数：x→0+ 时 |x| = x，比值为 x/x = 1。

3

左右导数不等，所以不可导

−1 ≠ 1，导数不存在。两句话都成立，命题正确。

用到：极值定义（邻域内比较大小）；左右导数与可导的充要条件。

常见错判：判“错误”，理由是“不可导就不可能有极值”。这正是这道题要打破的误解：极值只看大小关系，不看导数存不存在。

4选择关于函数的极值点，下列说法正确的是（　）
A. 一定是驻点B. 驻点一定是极值点C. 可能是驻点，也可能是导数不存在的点D. 一定在区间端点上
答案C

解析 · 一步一步来

1

先把“驻点”和“极值点”这两个概念分开

驻点 = 导数为 0 的点（一个方程的解）；极值点 = 函数在它附近取到局部最大或最小的横坐标（一个大小关系）。两者定义完全不同。

2

用反例检验 A：“极值点一定是驻点”

f(x) = |x| 在 0 处是极小值点，但 0 处不可导，不是驻点。A 错。

3

用反例检验 B：“驻点一定是极值点”

f(x) = x3 在 0 处 f′(0) = 0，是驻点，但函数一路递增，不是极值点。B 错。

4

检验 D，并确认 C

极值是在某点的“双侧邻域”内比较大小，端点只有一侧，所以端点不叫极值点，D 错。把 A、B 的反例合起来看：极值点要么是驻点（如 x2 在 0），要么是不可导点（如 |x| 在 0），C 正确。

用到：驻点定义；极值定义；两个标准反例 |x|（破 A）与 x3（破 B）。

错项排查

  • A反例 |x|：极值点但不可导，不是驻点。
  • B反例 x3：驻点但不是极值点。
  • C把两类情况都包含进去，与两个反例都不冲突，正确。
  • D端点只有单侧邻域，按定义不算极值点；端点上的大小只在求最值时考虑。
5计算求 f(x) = x4 − 2x2 的极值。
答案极大值 f(0) = 0；极小值 f(−1) = f(1) = −1

解析 · 一步一步来

1

求导

f′(x) = 4x3 − 4x。

2

提公因式，再分解成三个一次因式

4x3 − 4x = 4x(x2 − 1) = 4x(x − 1)(x + 1)。令其等于 0，得 x = −1、0、1 三个驻点。

3

三个驻点把数轴分成四段，逐段取测试点判号

取 x = −2：4(−2)(−3)(−1) = −24 < 0；
取 x = −0.5：4(−0.5)(−1.5)(0.5) = 1.5 > 0；
取 x = 0.5：4(0.5)(−0.5)(1.5) = −1.5 < 0；
取 x = 2：4(2)(1)(3) = 24 > 0。

4

按“左负右正极小、左正右负极大”逐个判定

x = −1：左负右正 → 极小值；
x = 0：左正右负 → 极大值；
x = 1：左负右正 → 极小值。

5

把三个点分别代回原函数算函数值

f(−1) = 1 − 2 = −1；f(1) = 1 − 2 = −1；f(0) = 0 − 0 = 0。所以极大值 0（在 x = 0 处），两个极小值都是 −1（在 x = ±1 处）。

用到：第一充分条件；因式分解；偶函数性质（f(−x) = f(x)），所以 x = ±1 处的极值必然相等。

常见错答：漏掉 x = 0（提公因式后只解了 x2 − 1 = 0）；只答一个极小值；把极大值 0 当成“没有极值”。

六高频易错点，考前必须过一遍

这些不是难题，是每年都在扣分的地方。看的时候对着自己的做法比一比。

1
极限存在 ≠ 函数有定义 ≠ 连续。

(x2−1)/(x−1) 在 x = 1 处极限是 2，但函数没定义，所以不连续。三件事要分开说：极限只看“靠近时的趋势”，连续还要求“函数值接得上”。为什么容易错：题目问“极限”时顺手写了“连续”，两问的答案本来就不一样。

2
可导一定连续，连续不一定可导。

方向别写反：|x| 在 0 处连续但不可导，是标准反例。判断技巧：遇到“连续是否可导”，先想尖点；遇到“可导是否连续”，直接用定理，不用举例。

3
导数定义式的分子分母必须“配平”。

lim(h→0)[f(x0+2h) − f(x0)]/h = 2f′(x0)，不是 f′(x0)。分子增量是 2h，分母就得是 2h，多出来的系数提到外面。这是选择题最爱设的坑：看到增量不是 h，先配平再算。

4
分段函数在分界点求导，必须用定义。

分别算左导数 lim(x→x0−)[f(x)−f(x0)]/(x−x0) 和右导数，两者相等才可导。直接求导只保证分界点两侧的表达式可导，不保证在分界点接得上。

5
极值点是 x，极值是 y。

规范写法：“在 x = −1 处取极大值 2”。只写“极大值为 −1”是把横坐标当成了极值，直接判错。填空、大题都按这个格式写，能避免一半的表述扣分。

6
驻点不一定是极值点，极值点也不一定是驻点。

x3 在 0 处导数为 0 但不是极值；|x| 在 0 处是极值但不可导。两句话要成对记，只记半句就会在判断题翻车。

7
求最值别漏端点和不可导点。

最值候选只有三类：驻点、导数不存在的点、区间端点。只算驻点是本题型第一大失分原因，尤其是端点恰好取到最大值的时候。

8
单调区间不能写成并集。

正确写法：单调递增区间是 (−∞,−1) 和 (1,+∞)，或者用逗号隔开；写成 (−∞,−1) ∪ (1,+∞) 是错的，因为函数在这两段之间不保持同一单调性。这是格式分，记住用“和”。

9
等价无穷小只能替换乘积因子。

lim(x→0)(tan x − sin x)/x3 里把 tan x、sin x 各自换成 x 会得到 0，是错的；正确做法是先提公因子：tan x − sin x = tan x(1 − cos x) ~ x·(x2/2) = x3/2，所以极限是 1/2。原因：加减法里替换会改变高阶项的抵消关系，只有乘除才能直接换。

10
隐函数求导别丢 y′。

对 y2 求导得 2y·y′，对 sin y 求导得 cos y·y′。只要式子里有 y，求导后就必须挂一个 y′，最后再解出来。
