TAMPERMONKEY SCRIPT

给任何网站的视频加一个倍速面板

装上脚本后，只要页面里有 HTML5 视频，右下角就会出现「⚡ 1×」悬浮按钮：学习通、B站、慕课、YouTube、网盘播放器都能用。0.5–16× 随意调，支持预设、微调、快捷键、拖动位置与记忆。脚本只改 video.playbackRate，不碰账号、密码、课程数据。

安装脚本 先装 Tampermonkey

Chrome / Edge / Firefox 都可以。手机浏览器需支持油猴（如 Kiwi），不如电脑稳。

三步装好

  1. 给浏览器装 Tampermonkey（油猴）：Chrome 应用商店 / Edge 加载项里搜「Tampermonkey」，点安装。
  2. 回到本页，点上面的「安装脚本」。油猴会弹出安装页，点「安装」即可。
  3. 随便打开一个有视频的网页（学习通课程、B站、慕课、YouTube 都行），右下角出现「⚡ 1×」就成功了。点它展开倍速面板。

怎么用

  • 点「⚡」展开面板，点 0.5× / 1× / 1.5× / 2× / 3× / 4× … 16× 直接切换。
  • − / + 每次调 0.25×；1× 一键复位。
  • 键盘：[ 减速、] 加速、\ 复位。
  • 倍速会记住，下次打开自动沿用；面板展开状态也会记住。
  • 胶囊可以拖动，位置会保存，不挡站点自己的按钮。
  • 全屏播放时面板会跟着进全屏，照样能调。
  • 视频在 iframe / Shadow DOM 里也能识别（脚本对所有站点生效，含播放器子页）。

常见问题

装了但右下角没有「⚡」？

先刷新页面；确认 Tampermonkey 图标上显示脚本已启用。面板只在页面里存在 HTML5 <video> 时出现，纯 Canvas 自绘播放器、Flash、或完全走 DRM 的封闭播放器可能识别不到。视频在 iframe 里时，面板会出现在 iframe 自己的右下角。仍然没有的话，打开 Tampermonkey 面板看「网页视频倍速」是否被禁用。

倍速被自动改回 1×？

部分播放器会在暂停 / 拖动进度 / 切集后重置倍速。脚本会尝试恢复（最多每 600ms 一次）。如果仍被反复重置，说明该站点有异常倍速检测，别硬来。

为什么最高只有 16×？

浏览器原生 playbackRate 一般上限就是 16×，再高会被截断。想要更快只能靠跳帧补偿，那会破坏播放器状态、丢失画面，脚本没有做。

会不会在所有网站都弹面板？

脚本匹配所有站点，但只有检测到视频才显示面板，普通网页不会出现。如果想让它在某些站彻底不运行，可以在 Tampermonkey 里给这个脚本加「用户排除」（User Exclude）。

装过旧版「学习通倍速」怎么办？

旧版只匹配 chaoxing.com。请先在 Tampermonkey 里把旧版删掉，再装新版，否则两个悬浮球会叠在一起。新版 @name 是「网页视频倍速」，版本号 2.0.0。

使用边界

仅用于你已获得访问权限的内容的个人回看加速。 部分课程 / 考试平台会检测异常倍速，可能导致学习进度无效或账号被标记；不要用于刷课、考试或代替实际学习。由此产生的后果由使用者自负。
