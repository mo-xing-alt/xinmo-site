TAMPERMONKEY SCRIPT

给任何网站的视频加一个倍速面板

装上脚本后，只要页面里有 HTML5 视频，右下角就会出现「⚡ 1×」悬浮按钮：学习通、B站、慕课、YouTube、网盘播放器都能用。0.5–16× 随意调，支持预设、微调、快捷键、拖动位置与记忆。脚本只改 video.playbackRate，不碰账号、密码、课程数据。

安装脚本 先装 Tampermonkey

Chrome / Edge / Firefox 都可以。手机浏览器需支持油猴（如 Kiwi），不如电脑稳。

三步装好

  1. 给浏览器装 Tampermonkey（油猴）：Chrome 应用商店 / Edge 加载项里搜「Tampermonkey」，点安装。
  2. 回到本页，点上面的「安装脚本」。油猴会弹出安装页，点「安装」即可。
  3. 随便打开一个有视频的网页（学习通课程、B站、慕课、YouTube 都行），右下角出现「⚡ 1×」就成功了。点它展开倍速面板。

怎么用

  • 点「⚡」展开面板，点 0.5× / 1× / 1.5× / 2× / 3× / 4× … 16× 直接切换。
  • − / + 每次调 0.25×；1× 一键复位。
  • 键盘：[ 减速、] 加速、\ 复位。
  • 倍速会记住，下次打开自动沿用；面板展开状态也会记住。
  • 胶囊可以拖动，位置会保存，不挡站点自己的按钮。
  • 全屏播放时面板会跟着进全屏，照样能调。
  • 视频在 iframe / Shadow DOM 里也能识别（脚本对所有站点生效，含播放器子页）。
  • 暂停自动续播：开 2× 以上时，若平台检测到高倍速强行暂停视频，脚本会自动续播（面板底部可开关）。你自己手动点的暂停不会被打断；降到 1× 时该功能不启用。
  • 平台限速保护：抖音最高锁 4×、学习通/中国大学MOOC 最高锁 2×——这些平台会把非原生倍速重置回 1× 或对高倍速风控（弹"网络不稳定"/验证码）。脚本会自动限速并每 250ms 抢回被重置的倍速，避免触发风控。其它网站不限速（最高 16×）。
  • 强制模式（3.0 新增）：面板底部金色按钮，开启后无视平台限速（可开满 16×），并从底层锁死倍速——平台改不回 1×、也停不掉视频。默认关闭，需手动开。逃生阀：Shift + \ 立即关闭。

⚠ 强制模式说明与风险：它只突破浏览器前端的限制（改倍速、暂停、假弹窗）。无法突破平台服务端的风控——如学习通的「操作异常验证码」、学习时长统计，这些判定在服务器上，前端脚本无能为力；触发后仍需你人工处理。强行高倍速刷网课可能违反平台规则、影响账号，请自行斟酌、谨慎使用。

常见问题

装了但右下角没有「⚡」？

先刷新页面；确认 Tampermonkey 图标上显示脚本已启用。面板只在页面里存在 HTML5 <video> 时出现，纯 Canvas 自绘播放器、Flash、或完全走 DRM 的封闭播放器可能识别不到。视频在 iframe 里时，面板会出现在 iframe 自己的右下角。仍然没有的话，打开 Tampermonkey 面板看「网页视频倍速」是否被禁用。

开 2× 以上弹出「网络不稳定，请稍后继续」？

这是学习通 / 中国大学MOOC 等平台伪装的倍速检测提示——不是真的网络问题，而是检测到你开了高倍速，故意弹窗打断播放。脚本 2.2 起会自动拦截这类假弹窗（真正的其它提示照常显示），并配合「自动续播」让视频继续。保持面板底部开关 ✓ 防打断 即可。若平台改用需要人工点确认的其它方式，建议降到 2×。

抖音上倍速总是自动变回 1×？

抖音会把「非平台原生的倍速」周期性重置回 1×。脚本 2.3 起每 250ms 主动抢回倍速，并把抖音上限锁在 4×（够用且更稳）。你设 8× 时实际显示「4×·限4×」是正常的。刷新页面后生效。

什么是「强制模式」，会被封号吗？

强制模式（面板金色按钮）从底层锁住倍速：平台把速度改回 1×、或调用暂停，都会被脚本挡回去，无视站点限速。它只在你的浏览器里生效，不修改平台服务器数据。但要注意：网课平台的服务端会记录你的学习行为（播放心跳、时长、验证码），高倍速仍可能被平台判定异常、要求人工验证甚至影响成绩——这部分脚本管不了。建议只在自己复习、不考核时长的场景使用，别用来刷课。

强制模式卡住了/想恢复普通？

按 Shift + \ 立即关闭强制模式；或点面板金色按钮切成 ◇。关闭后限速保护恢复正常。

倍速被自动改回 1×？

部分播放器会在暂停 / 拖动进度 / 切集后重置倍速。脚本会尝试恢复（事件 + 每 250ms 定时兜底）。学习通/中国大学MOOC 为避开风控已锁 2×；其它站点若仍被反复重置，说明有异常倍速检测，别硬来。

为什么最高只有 16×？

浏览器原生 playbackRate 一般上限就是 16×，再高会被截断。想要更快只能靠跳帧补偿，那会破坏播放器状态、丢失画面，脚本没有做。

会不会在所有网站都弹面板？

脚本匹配所有站点，但只有检测到视频才显示面板，普通网页不会出现。如果想让它在某些站彻底不运行，可以在 Tampermonkey 里给这个脚本加「用户排除」（User Exclude）。

装过旧版「学习通倍速」怎么办？

旧版只匹配 chaoxing.com。请先在 Tampermonkey 里把旧版删掉，再装新版，否则两个悬浮球会叠在一起。新版 @name 是「网页视频倍速」，版本号 2.0.0。
