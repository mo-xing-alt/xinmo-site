    这些谱从哪里来

    曲谱来自 thesession.org 的公开曲调库。这是一个收录传统民谣舞曲的社区站点，曲调本身为世代流传的公有领域旋律；本库使用会员贡献的 ABC 记谱，并逐首保留记谱者署名、原始链接与贡献日期（对应站点 CC BY-SA 的署名要求）。

    本库不含从商业曲谱站批量抓取的流行歌曲谱面。流行/影视曲的简谱通常受词曲著作权与记谱者权利保护，把它们搬到公开站点会带来侵权风险。如果你拥有某批曲谱的合法授权，可以按下面的方式整体替换数据集。

    「1000 首」是怎么选出来的

    抓取约 1500 个曲调条目 → 解析 ABC 记谱 → 过滤掉音符过少、无法成谱的条目 → 按被社区收录进球本的次数（tunebooks）降序取前 1000 首 → 按「曲名 + 旋律指纹」去重。热度是真实社区数据，不是人工编的推荐位。

    简谱是怎么生成的

    ABC 的每个音符被解析成绝对 MIDI 音高与十六分音符时值，页面按首调唱名法实时换算成 1–7、八度上下加点、增减时值线与休止符 0，因此可以自由移调。变化音用 ♯/♭ 标在数字前。左手伴奏优先采用原谱和弦标注，没有标注时按调式自动生成 I / IV / I / V 分解低音。

    难度 1–5 由真实音乐特征算出综合分（音符数、音域跨度、最短时值、大跳比例、变化音密度），再按全库五分位分级：1 = 最容易的 20%，5 = 最难的 20%，可直接按水平选曲。

    替换成你自己的谱

    数据文件是 tools/piano-jianpu/data.js，结构为 window.JIANPU_DATA = { meta, tunes: [...] }。每首曲子包含 n 曲名、k 调性、tp 主音音级、pat 调式音程、m 拍号、d 难度、st 统计、seq 音序（midi/ticks 空格分隔，R/t 休止，| 小节，|: / :| 反复）、ch 每小节和弦、bass 每小节左手音。按同样格式生成即可，页面无需改动。

    中文热曲 1000 首为什么是目录

    「爆火中文钢琴曲」几乎都还在词曲著作权保护期内，谱面（含简谱改编）属于受保护的表达；把它们批量搬到公开静态仓库会构成侵权， 商业曲谱站点的服务条款也普遍禁止批量下载。所以这一栏只放事实元数据：曲名、歌手、站内热度档、歌单收录次数和原曲链接—— 这些是可以合法使用的客观信息，不含歌词、不含任何曲谱。

    数据来自开源研究数据集 LindiaC/music163-mining（网易云音乐歌单挖掘，24.4 万首华语歌曲、634 个歌单）。 热度定义为「被多少个热门歌单收录，并按歌单收藏量/播放量加权」，是数据集内的相对流行度，不是官方榜单。 已合并 Live / DJ / 伴奏等版本，只保留录音室原版曲名，剔除虚拟歌手条目，按曲名 + 歌手去重后取前 1000 首。

    这一栏的曲目不进入可弹奏简谱曲库，也不参与左侧 1000 首的调性/难度统计；它们有自己独立的统计面板。如果你拥有某批曲谱的合法授权，把它们给我，我可以批量转换成真正可弹奏、可打印的双手简谱并合并进曲库。
