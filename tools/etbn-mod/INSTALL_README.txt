========================================
 ETBNightmareMod 安装说明（Escape the Backrooms / Steam 版）
========================================

【这是什么】
给《Escape the Backrooms》加的一把"信号枪"武器（能打死实体，含细菌/蜘蛛/触手怪），
外加无限体力、F6 普通奔跑、F7 三倍速、F8 圣诞皮肤。
纯本地文件，不联网、不改游戏存档。

----------------------------------------
【安装：三步】
----------------------------------------
1) 先把游戏完全退出（Steam 里也确认已停止）。

2) 找到游戏的这个文件夹：
   ...\steamapps\common\EscapeTheBackrooms\EscapeTheBackrooms\Binaries\Win64
   （注意：路径里有两个 EscapeTheBackrooms，进到 Binaries\Win64 这一层，
     里面能看到 EscapeTheBackrooms-Win64-Shipping.exe 就对了）

3) 把下载的 ETBNightmareMod_FullCopy.zip 解压，
   把里面的 dwmapi.dll 和 ue4ss 文件夹，整个复制进上面的 Win64 文件夹。
   —— 如果 Win64 里已经有 ue4ss 或 dwmapi.dll，先把旧的改名备份再复制。

----------------------------------------
【进游戏怎么用】
----------------------------------------
· 按 ~（波浪键）或 , 或 F10 打开控制台
· 输入 etbn help 看全部命令
· F6 = 普通无限体力奔跑      F7 = 三倍速
· F8 = 切换圣诞皮肤          G = 开枪（对准实体）
· 皮肤默认是关的，想要就按 F8，或输入 etbn skin christmas

----------------------------------------
【联机】
----------------------------------------
· 每个一起玩的人都要装这个包。
· 想全体三倍速：所有人各按一次 F7，再由房主输入 etbn sync on。
· 别人进你房间 Shift 不能加速？房主按一次 F6 就好了。

----------------------------------------
【出问题】
----------------------------------------
· 游戏打不开：多半是杀毒拦截 dwmapi.dll，加白名单即可。
  实在不行，删掉 Win64 里的 dwmapi.dll 和 ue4ss 文件夹就完全恢复原版。
· 控制台没反应：确认 Win64\ue4ss\UE4SS-settings.ini 里有 ConsoleEnabled = 1。
· 想看日志：Win64\ue4ss\UE4SS.log

----------------------------------------
【卸载（恢复原版）】
----------------------------------------
删掉 Win64 里的 dwmapi.dll 和 ue4ss 文件夹即可。

把压缩包里的 AI_INSTALL_GUIDE.md 发给你的 AI 助手，
它能照着一步步帮你装好。
