常见问题

点开看处理办法。

游戏打不开 / 启动就退？

多半是杀毒软件拦截了 dwmapi.dll（代理注入常见误报）。把游戏目录加入白名单即可。实在不行，删掉 Win64 里的 dwmapi.dll 和 ue4ss 文件夹就完全恢复原版。

控制台按 ~ 没反应？

确认 Win64\ue4ss\UE4SS-settings.ini 里有 ConsoleEnabled = 1。也可以直接看 Win64\ue4ss\UE4SS.log，里面有 Starting Lua mod 'ETBNightmareMod' 就说明已生效。

派对客还是原皮？

皮肤默认是关的：进关等几秒后按 F8，或输入 etbn skin christmas。若游戏内材质加载不到，会自动回退引擎材质（仍是可见新皮）。用 etbn skin assets 查看素材状态。

联机三倍速没用 / 队友跑不动？

每个人都要装这个包。要全队三倍速：所有人各按一次 F7，再由房主输入 etbn sync on。别人进你房间 Shift 不能加速时，房主按一次 F6 即可恢复。

某些怪打不死？

确认用的是最新包。用 etbn hits 或 etbn scan all 查看类名，再用 etbn entity <关键词> 临时补。

怎么卸载、恢复原版？

完全退出游戏，删掉 Win64 里的 dwmapi.dll 和 ue4ss 文件夹即可；有备份的再把 dwmapi.dll.bak-etbn / ue4ss.bak-etbn 改回原名。
