三种模式，想要哪种都行

默认推荐「完全原版」；不想动加载器就选「只禁用模组」。

完全原版（推荐）

移走 dwmapi.dll 和整个 ue4ss 文件夹。没有加载器、没有模组，和刚从 Steam 装完一样。

只禁用模组

保留 UE4SS 加载器，只移走 Mods\ETBNightmareMod，并换成「全部为 0」的干净 mods.txt。

备份 + 撤销

被移走的东西放进 _ETB_mod_backup_时间戳 文件夹；运行 --undo 就能原样搬回去。

常见问题

点开看处理办法。

会不会把文件删掉 / 把存档弄没？

不会。工具只有「移动」，没有删除操作；Mod 文件全部进入带时间戳的备份目录。存档、成就、Steam 设置本来就没被模组改过。

还原后还是无限体力、还能三倍速？

多半是游戏进程没退干净，文件被占用。任务管理器结束 Backrooms-Win64-Shipping.exe 后重新运行一次 --mode full。

我想以后再玩模组怎么办？

运行 --undo 把备份搬回来；或者重新下载「“噩梦”模组」的 FullCopy 包，按它的安装说明复制进去。

电脑上没有 Python 怎么办？

可以先装 Python 3（安装时勾选 Add to PATH），或者把这个包连同 AI 还原指南发给大模型，让它用命令行替你操作。Steam 版游戏的原版文件本身不需要 Python。

Steam 的「验证游戏完整性」能还原吗？

它只修复游戏自带文件，通常不会删除 Win64 里多出来的 dwmapi.dll 和 ue4ss 文件夹。所以还是要先用这个包把它们移走。

和「“噩梦”模组」页面是什么关系？

那个页面是装模组，这个页面是把模组卸干净。两个包互不依赖，可以随时来回切换。前往模组页 →
