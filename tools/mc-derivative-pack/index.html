1朋友手动安装步骤（不用 AI 也能装）

    
    
      
  1. 点下方「分卷下载」，把 part01 到最后一个分卷以及 parts-manifest.json、合并脚本 全部下载到同一个文件夹。
    2. 
      
  2. 双击 merge.bat（Windows 会自动用 Python 或 PowerShell）。看到 MERGE OK 就合并成功了。
    3. 
      
  3. 把合并出来的 Derivative-Main-v4-一键安装包.zip 解压整个文件夹。
    4. 
      
  4. 确认 PCL 里已装原版 Minecraft 26.1.1；然后把 .minecraft 文件夹拖到 Install.bat 上（或直接双击）。
    5. 
      
  5. PCL 版本列表里展开折叠卡片，选 fabric-loader-0.20.1-26.1.1 启动。光影已预启用。
    6. 
      
  6. 进游戏后：选项 → 资源包，启用 Patrix 32x 和 Continuity 内置的两个包（无缝玻璃/连接纹理）。
    7. 
    

    

      ⚠️ 不要在 MC 26.3 上启用这个光影，会花屏。本包专为 26.1.1 准备。PCL 会把 26.1.1 和 26.3 折到同一张卡片，要展开才看得到。

3常见问题

    
合并时提示某个分卷损坏？
那个分卷下载不完整，单独重新下载它再运行合并脚本即可。其余分卷不用重下。

    
启动崩溃 / mod 冲突？
把 logs/latest.log 发给大模型或站主。34 个 mod 已做静态依赖核对，运行期交互需实机确认；可删掉后加的内容 mod 回退到 4 核心。

    
材质包提示"为旧版本制作"？
Stay True 是 1.21.5 的包，点"是"强制加载即可；Patrix 32x 是 26.1.x 专用，不会有此提示。

    
玻璃没连起来 / 树叶不蓬松？
Continuity 装了不等于生效，必须在资源包菜单启用它内置的两个包，且 Patrix 要排在它们上面。
