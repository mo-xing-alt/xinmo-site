Minecraft 26.1.1 · Derivative 光影一键安装包
================================================

给朋友的三句话说明：
1. 把本站 21 个分卷 + parts-manifest.json + 合并脚本下载到同一个文件夹。
2. 双击「merge.bat」，看到 MERGE OK 就得到完整安装包 ZIP。
3. 把 ZIP 发给大模型 + 复制本站页面上的「给大模型的安装指令」，它会自动装好。

不用 AI 也能装：解压 ZIP → 把 .minecraft 拖到 Install.bat → PCL 选 26.1.1 启动。

包含什么：Derivative 光影（已修雨闪光/玻璃透明）、Continuity 无缝玻璃、
Patrix 32x + Stay True 材质包、SnuggleCraft 休闲内容（家具/生物/地图/动态光等 34 mod）。

注意：只在 MC 26.1.1 用，26.3 上会花屏。
完整步骤和大模型指令见：
  - index.html（本站页面，有一键复制按钮）
  - AI-GUIDE.md（给大模型的完整 Markdown 说明）
