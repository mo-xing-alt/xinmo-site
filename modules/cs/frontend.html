知识地图

先把地图铺开，再决定今天走哪一段路。

01

语义化结构

用正确的标签表达正确的内容：标题层级、表单语义、图片替代文本，是一切可访问性与可维护性的起点。

02

布局体系

Flex 与 Grid 各自的适用场景、移动优先的响应式断点、容器查询，让同一套代码适配从手表到大屏。

03

JavaScript 核心

事件循环、闭包、原型链、异步与错误处理：理解语言模型，才能写出不靠运气的代码。

04

浏览器渲染

解析 → 样式计算 → 布局 → 绘制 → 合成，理解五个阶段，就知道该在哪里省下那几十毫秒。

05

工程化与构建

模块化、Vite 构建、按需加载、缓存策略：把一个人的项目，做成能协作、能长期维护的工程。

06

性能与可访问

Core Web Vitals、图片格式选择、对比度、键盘可达、prefers-reduced-motion，让更多人用得舒服。
